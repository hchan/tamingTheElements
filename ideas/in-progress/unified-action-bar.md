# One consistent action bar

Owner: "needs to be consistent ... NO icons on the right please. all should be aligned as boxes on the left with icons (and good icons/sprites)".

Done in this work package:
- Every action (abilities, Snag, Tag, Trap, Element, Super, Guard, Dash, Weather, Charge) is the same kind of box in one left-aligned run on the canvas
  action bar, each with an icon, a key label and a cooldown. No text-only boxes, no right-hand chips; rows wrap upward on the left, never to the right.
- Icons: reused hero/ability sprites where they exist; the rest come from `public/assets/img/hud/actions.png`, generated by `tools/assets/hud-gen/actions.py`
  (grim, desaturated, textured). The look is graded the same way as Fiara's art.
- One cooldown animation for every box: `cooldownLook` -> `drawCooldown` (same shade, same eased ready flash, same colour); reduced motion is a static shade
  with no flash or pulse. Pinned by `tests/repo/one-cooldown-renderer.test.ts` and the view test.
- The DOM touch buttons (`#arcadeSuper` ...) stay as transparent overlays over their boxes (`src/game/hud/touch-overlay.ts`) so hold, aria, keyboard and the
  e2e ids are unchanged.

Follow-ups:
- The old touch size/side settings (`data-touch-size`, `data-touch-side`) no longer move the buttons; retire the settings or map size to the box scale.
- Hand-drawn icon art is procedural; replace with painted sprites when an artist pass is available.
