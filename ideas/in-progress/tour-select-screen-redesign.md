# Tour screen redesign: Marvel vs Capcom style select, dark fantasy

Owner feedback (2026-11-13, screenshot of #tour): the Tour screen is plain text, a small map and a text list; it "needs to be better, think Marvel vs Capcom selection", with graphics in the common theme of the new dark fantasy heroes.

## Sketch

- Big stage-select layout: a stylised dark world map or node strip with large element-themed stage tiles (painted, grim, desaturated), the current stage highlighted with an animated frame.
- Opponent roster shown as portraits (grim-graded hero art), element badges, difficulty and continues as icons not sentences.
- Locked stages as silhouettes; cleared stages stamped. Keyboard, gamepad, touch and mouse; 800x450 and 48 px touch targets.
- Drop the serif default and yellow title; reuse the grim HUD/menu type and palette. Related: [[mvc-character-select-with-ability-info]], [[sf-world-map-tour]].
