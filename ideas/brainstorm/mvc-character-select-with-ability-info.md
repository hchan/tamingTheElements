# Marvel vs Capcom style character select, with abilities explained

Owner idea (2026-11-13): the main menu's character choice is a drop-down, which is ugly. Replace it with an MvC-style select, and show each hero's abilities and WHAT they do when selecting.

## Sketch

- Portrait grid of all 12 heroes grouped by element (water, air, fire, earth), cursor with keyboard, gamepad, touch and mouse; P1 and P2 cursors for Versus.
- Focused hero shows a large portrait (grim-graded hero art), name, element, and stats (life, speed, size).
- Ability panel: each ability with icon, name, key and a one-line plain description (damage, cooldown, what it does to the foe, e.g. Snag roots, trap, weather), generated from the character data so it cannot drift.
- Confirm/lock-in animation and sound; random pick; works at 800x450 and with 48 px touch targets.
- Player-facing words: no Classic/Arcade/ruleset/Capture. Related: [[mvc-3v3-select-and-regen]].
