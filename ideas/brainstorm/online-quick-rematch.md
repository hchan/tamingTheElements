# Online quick match: rematch with the same opponent

Play again currently re-queues, so the next opponent is random. A rematch offer (both press Again, the service pairs the same two) would keep a good game going. Needs a protocol frame for "rematch with my last opponent" (see ONLINE-PROTOCOL.md; the fake service already has `startMatch` for a rematch pair) and a short timeout back to the queue.
