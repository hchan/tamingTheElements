# Portrait tall arena (deferred)

The portrait fight uses the 1280x720 view scaled to 390 px wide (about 219 px tall), which leaves most of the screen to controls. A real portrait view (a taller camera, EXPAND scale mode or a cropped zoom) would use the space for the arena itself. Rejected for now because it changes the 1280x720 view, the HUD layout and the camera, and needs sim-visible arena width decisions. Revisit once the pinned layout (portrait-fight-layout) has been judged.
