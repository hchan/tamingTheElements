# Snag has no visible home on desktop or touch (r13)

Snag has no keycap or action-bar slot on desktop, no touch button, and no line in Help (action bar list and all control tables omit it). The bar on Echo shows a "1 Snag" icon while the first-run hint says to strike with 1, which conflicts. Curomo shows "2 Snag". Screens: 80-c-echo-0.png, 81-slot-tooltip.png, 90-touch-land-1v1-hint.png (landscape strip omits Snag).

Fix: add a Snag slot labelled C to the bar and a Snag touch button for heroes that have it, add Snag rows to Help, and make the hint and bar icon agree.
