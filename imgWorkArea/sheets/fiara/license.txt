Rig parts for fiara, cut with tools/rig-assist/cut.py --no-sam (hand-drawn polygons), then re-split for translucency.

Source sprite: public/assets/img/map/fiara.png, frame col 0, row 0, crop 0,0,80,80 (the legacy rest frame, facing east).
Source sprite provenance and licence: legacy Taming the Elements game art (Crafty.js version, git tag legacy-crafty-1.0),
  owned by the project owner. Licence: TO BE CONFIRMED BY THE OWNER before these parts are committed (the project licence is
  still "to be decided" in README.md).
Edits: parts cut and underlap-filled automatically (edge-extend colour). Because the sprite is translucent (alpha about 76 %),
  the underlap alpha was feathered (ramped down with distance from the seam, capped below the covering pixel's alpha) and the
  covering pixels re-solved so the rest pose composites back to the legacy frame within 1/255. SE and NE part variants are the
  E parts rotated 8 degrees (premultiplied bicubic) with the back wing narrowed to 90 %. No hand retouching.
  Done by Claude (WP5 Fiara vertical slice, 2026-11-11) for owner review.
Licence of these parts: same as the source sprite.
Segmentation model: none (--no-sam; the masks are hand-drawn polygons).
