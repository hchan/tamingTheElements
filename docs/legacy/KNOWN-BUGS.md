## Port-found fixes and unreproduced legacy behaviour

| Slug | Description | New test |
|---|---|---|
| `rest-heal-stacking` | Legacy `benchHelper` creates a new `HealWithRest` timer on every bench and never stops the older ones until each passes the cap, so a character benched N times below its cap can heal N times per second. The port keeps one timer per character, restarted at each bench (divergence recorded, not reproduced: it needs an unbounded timer list) | `src/core/sim/systems/death-swap-rest.test.ts` (`starts the timer at the bench tick`) |
| `projectile-table-leak` | In legacy, entities are unbounded. In the port a cast with a full entity table is now refused, so it books no cooldown and leaks no active count (intentional divergence, parity row C18) | `src/core/sim/systems/projectile.test.ts` (`a cast with a full entity table books no cooldown and leaks no active count`) |
